Infynitae file manager

Mock-up for docs/FILE_MANAGER.md using the shipped default theme colours (#111317 surface, #333b54 border, #eef2f8 text, #a7abb0 muted, #7aa2f7 accent, #ed6a6f alert, 8 px window corners, 4 px inner corners), matching docs/mockups/file-picker.html. Every control works: switch or add tabs, toggle Split view (F3), right-click any file or drive, press F2 to rename, Delete to move to Trash, Ctrl+Z to undo, Alt+Enter for Properties, pause or cancel the active transfer, resolve the name conflict, or mount Drive VI.

Manager window (tabs, split view, active copy progress, name conflict)

Ready. Right-click any file, folder, or drive (try Drive V) to open its context menu, or click Replace, Keep both, or Skip on the docked conflict bar.

Trash (restore and empty) and right-click menus

Select an item in Trash and click Restore, click Empty trash to see the confirmation bar, or click any item in the two example context menus below.

Example data: all folders, file names, dates, sizes, drive free-space figures, Trash entries, and the 336 GB Music transfer are sample entries so every interaction can be tried here. In the running desktop, Places reads ~/.config/user-dirs.dirs, ~/.config/gtk-3.0/bookmarks, ~/.local/share/recently-used.xbel, /etc/fstab, and /proc/self/mountinfo, Trash reads Freedesktop Trash folders per drive, and all colours come from ~/.cache/infynitae/look.
