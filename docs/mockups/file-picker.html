Infynitae file picker

Mock-up for docs/FILE_PICKER.md using the shipped default theme colours (#111317 surface, #333b54 border, #eef2f8 text, #a7abb0 muted, #7aa2f7 accent, #ed6a6f alert, 8 px window corners, 4 px inner corners). Both windows work: browse Places and drives I to VI, click Drive VI to mount it, click the path bar or press Ctrl+L to type a path, filter, search, switch List and Grid, toggle Preview, create a folder, or trigger an overwrite check in Save.

Open file (multiple selection, filters, preview)

Save as (filename, portal choices, overwrite check)

Waiting for save. Click Save right away to see the inline replace check for notes-2026.md, or type a new name.

Folder contents, file dates, sizes, and drive usage numbers are examples so every control can be tried here. In the running desktop, Places reads ~/.config/user-dirs.dirs, ~/.local/share/recently-used.xbel, /etc/fstab, and /proc/self/mountinfo, and all colours come from ~/.cache/infynitae/look.
