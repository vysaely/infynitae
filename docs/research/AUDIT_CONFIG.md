## Bugs

### 1. Quoting, escaping, `export`, and `#` handling split readers into two incompatible camps

* **Writers** mix styles: `live/settings.sh:1302-1303` (`set`) writes single quotes with shell escaping (`'O'\''Reilly'`), `live/edge-apps/src/config.rs:503` writes double quotes without escapes (rejecting `'`), `live/launch.sh:605-619` and `live/install-lib.sh:453` write/rewrite double quotes (`KEY="val"`), and `live/setup-autologin.sh:128` edits `START_LOCKED="[^"]*"`.
* **What breaks**:
  * `live/edge-apps/src/config.rs:510-520` (`value_text`) and `live/edge-apps/src/cards/settings_rows.rs:92-115` (`parse_config`) stop at the first `'` inside `settings.sh`'s `'a'\''b'`, turning `'O'\''Reilly'` into `"O"`. `value_text` in `edge-apps/src/config.rs:628` and `edge-rs/src/config.rs:565` also fails to strip `export ` or skip `#` comments cleanly (only surviving comments because `#KEY` fails key matching), rejects spaces before the opening quote, and misses unquoted trailing comments without space in some paths.
  * `live/edge/infynitae-edge.c:1701` (`config_text`), `live/portal/settings.c:61-88`, `live/portal/infynitae-portal.c:304`, `live/lock/infynitae-lock.c:329-360`, `live/polkit/infynitae-polkit.c:226-246`, and `live/wallpaper/infynitae-wallpaper.c:736-744` all do naive `strchr`/`memchr` on quotes without handling `'\''` or `\"`, and most (`lock.c`, `polkit.c`, `portal/settings.c`, `edge.c`, `edge-rs`) ignore `export KEY=...` lines that `config.sh`, `wayland::config_line`, and `portal/infynitae-portal.c:302` accept.
  * `live/control-menu:174` checks `ENABLE_REPLAY_BUFFER` via `grep -qE '^ENABLE_REPLAY_BUFFER="?(true|1|yes|on)"?' "$CONFIG"`. Because `quick.rs:174` toggles replay via `settings.sh set ENABLE_REPLAY_BUFFER true`, the file ends up containing `ENABLE_REPLAY_BUFFER='true'`, which `replay_on` does **not** match (so `control-menu` displays Replay Buffer Off while it is running) and `sed -i "s/^ENABLE_REPLAY_BUFFER=\"[^\"]*\"/..."` at `control-menu:178` leaves unreplaced unless toggled via `control-menu` itself. The same `sed` pattern fails for `BATTERY_LIMIT` (`control-menu:199`) and `START_LOCKED` (`setup-autologin.sh:128`) after `settings.sh` single-quotes them.
* **Proved by tests**: `audit_config_edge_value_text_decodes_escaped_single_quote`, `audit_config_parse_config_handles_escaped_single_quote_and_export`, `audit_config_edge_parse_hex_and_export`.

### 2. Removed `[save]` keys in `WaylandState::reload_config`, missing initial config reload, and mismatched startup/reset defaults

* In `crates/infynitae-wayland/src/lib.rs:1287-1559`, 32 keys (33 key names including `BORDER_ACTIVE`) mutate `self.*` or `self.core.*` directly inside `match key` with no reset before the loop:
  * Appearance / borders: `BORDER_WIDTH`, `CLIP_TO_GEOMETRY`, `BORDER_IGNORE_CSD`, `BORDER_INACTIVE`, `CANVAS_COLOR`, `SQUARE_CORNERS`, plus `ACCENT`/`BORDER_ACTIVE` (`1454-1463, 1595-1597`: only assigned `if let Some(c) = accent_color.or(border_active_color)`). Also `WaylandState::new` initializes `border_width: 0` at `crates/infynitae-wayland/src/lib.rs:865` while `config/config:165` defaults `BORDER_WIDTH="1"`.
  * Navigation / focus / placement / input / privacy: `PAN_MODE`, `FOCUS_FOLLOWS_MOUSE`, `FOCUS_CYCLE_NAVIGATE`, `FOCUS_ON_OPEN`, `TELEPORT_ON_OPEN`, `FOCUS_ON_ACTIVATE`, `SUPER_ENTER_ACTION`, `FULLSCREEN_PAN`, `KEEP_ON_TOP`, `PLACEMENT_POLICY`, `OSK`, `NIGHT_LIGHT_TEMP`, `CAPTURE_INDICATOR`, `SCREENCOPY_CURSOR`, `LATENCY_STATS`, `MOUSE_ACCEL_PROFILE`, `MOUSE_ACCEL_SPEED`, `TOUCHPAD_TAP`, `TOUCHPAD_NATURAL_SCROLL`, `SUPER_FREES_CURSOR`, `KEYBOARD_REPEAT_DELAY`, `KEYBOARD_REPEAT_RATE`, `PRIVACY_APPS`, `PRIVACY_TITLES`, `FORCE_TRANSPARENT_APPS`.
* `CURSOR_THEME` removal at `crates/infynitae-wayland/src/lib.rs:1638-1641` falls back to `env("CURSOR_THEME").or(env("XCURSOR_THEME")).unwrap_or("default")`, whereas `config/config:327`, `live/env.sh:93`, and `live/settings.sh:45` default to `"Adwaita"`.
* In `crates/infynitae-backend-drm/src/lib.rs:1754-1787` and `crates/infynitae-backend-winit/src/lib.rs:365-382`, the 250 ms watcher checks `if self.last_config_mtime.is_some()` before comparing `mtime`. If `~/.config/infynitae/config` did not exist at startup (`last_config_mtime == None`), creating the config later never triggers `reload_config()` (unlike `edge-apps` `shell::reload_if_changed`). Also `crates/infynitae-backend-drm/src/lib.rs:1771` does not reset `IDLE_SLEEP_TIMEOUT_MIN` to `15` when removed.
* **Proved by tests**: `audit_config_reload_resets_removed_save_keys_to_defaults`, `audit_config_wayland_state_new_border_width_is_one`.

### 3. Empty `""` or unrecognized values flip defaults instead of preserving documented defaults

* `PAN_MODE=""` (or invalid): `crates/infynitae/src/main.rs:607-613` (`parse_pan_mode`) maps unknown/`""` to `PanMode::Free`; `crates/infynitae-wayland/src/lib.rs:1298-1308` maps unknown/`""` to `PanMode::Grab` while `config/config:144` and `Core::new` default to `Free`.
* `TOUCHPAD_TAP=""`: `crates/infynitae-wayland/src/lib.rs:1478` runs `Some(parse_bool(val).unwrap_or(false))`, turning touchpad tapping **off** (`Some(false)`) when `TOUCHPAD_TAP=""` (missing key defaults to `true` via `crates/infynitae-backend-drm/src/lib.rs:4130-4134`). Same pattern for `TOUCHPAD_NATURAL_SCROLL`.
* `LATENCY=""`: `crates/infynitae-wayland/src/frame_schedule.rs:31-44` maps unknown/`""` to `LatencyMode::Balanced`, while `crates/infynitae-wayland/src/lib.rs:869` (`WaylandState::new`) and `config/config:248` default to `LatencyMode::Direct`.
* `PANELS_OVERLAP=""`: `live/edge-apps/src/config.rs:647-655` and `live/edge-rs/src/config.rs:677-684` compute `!matches!(t.as_str(), "false" | "off" | "no" | "0")`, turning empty `""` or invalid strings into `overlap = true` against default `false`.
* **Proved by tests**: `audit_config_pan_mode_empty_keeps_free_default`, `audit_config_touchpad_tap_empty_keeps_default_true`, `audit_config_latency_empty_keeps_direct_default`, `audit_config_edge_panels_overlap_empty_stays_false`.

### 4. `settings_display::TABLE` `(label, value)` tuple swap breaks `settings_all::shown_word`

* Every other settings table stores `Control::Pick(&[(value, label), ...])`, and `live/edge-apps/src/cards/settings_all.rs:1256,1265` searches `o.iter().find(|(v, _)| *v == value)`.
* `live/edge-apps/src/cards/settings_display.rs:35,67,76-80` defines `VRR_ENABLED`, `MAX_APP_SCALE`, and `SCALING_FILTER` options as `(label, value)`, so `shown_word("VRR_ENABLED", "on")`, `shown_word("MAX_APP_SCALE", "2")`, and `shown_word("SCALING_FILTER", "fsr")` return `None`.
* **Proved by test**: `audit_config_display_shown_word_tuple_order`.

### 5. Boolean acceptance disagrees across compositor, UI cards, and shell scripts

* `infynitae_wayland::parse_bool` accepts case-insensitive `1|true|yes|on` vs `0|false|no|off` (`crates/infynitae-wayland/src/lib.rs:2083`).
* `live/config.sh:90-95` (`infy_on`) accepts `1|true|yes|on|TRUE|True` (copied in `tools/config-cases:1-28`), rejecting `YES`/`Yes`/`ON`/`On`.
* `live/edge-apps/src/cards/settings_rows.rs:447,664` (`Switch`) matches only `eq_ignore_ascii_case(on)` (`"true"`, or `"1"` for `FOCUS_CYCLE_NAVIGATE`). `live/edge-apps/src/cards/settings_lock.rs:196` and `live/edge-apps/src/cards/settings_all.rs:1348-1359` only check `eq_ignore_ascii_case("true")` for `LOCK_WHEN_AWAY` and legacy keys. Setting `GAME_MODE="1"`, `LOCK_WHEN_AWAY="yes"`, or `FOCUS_CYCLE_NAVIGATE="true"` enables the feature in the compositor/shell while Settings renders the switch as OFF and clicking toggles it to the already-active state.
* `live/record/infynitae-recorder:78` checks `RECORD_NOTIFY != "true" && RECORD_NOTIFY != "1"` (`"yes"`/`"on"`/`"TRUE"` silently disable notifications).
* `live/launch.sh:304,318` checks `FREEZE_SCREENSHOT = true` literally (`"1"`/`"yes"`/`"on"`/`"TRUE"` disable freezing).
* `live/infynitae-reload:257` checks `ENABLE_EDGE != false` (`"0"`/`"off"`/`"no"` still satisfy it there, whereas line `212` uses `is_true`).
* `live/wallpaper/infynitae-wallpaper.c:760` (`WALLPAPER_PARALLAX`) accepts `"strong"` (`2`) and `"subtle"`/`"on"`/`"true"` (`1`); `"1"` and `"yes"` become `0` (off).
* **Proved by tests**: `audit_config_lock_when_away_on_accepts_shell_bool_tokens`, `audit_config_lock_card_accepts_shell_bool_tokens`, `audit_config_switch_accepts_shell_bool_tokens`.

### 6. Edge default accent is `#333b54` instead of `#7aa2f7`, and legacy edge builds diverge further

* `config/config:170`, `WaylandState::new:872`, `live/settings.sh:68`, `live/lock/infynitae-lock.c:427`, `live/polkit/infynitae-polkit.c:303`, and `live/portal/settings.c:93` all default accent to `#7aa2f7`.

### 7. `LOCK_WHEN_AWAY` vs `IDLE_AUTO_LOCK` vs `SLEEP_LOCK` three-way split

### 8. First-wins vs shell last-wins precedence on duplicate keys

* Because `~/.config/infynitae/config` is a POSIX `sh` file sourced via `.` (`live/config.sh:10`), later assignments override earlier ones (`last-wins`).
* Exceptions that stop at or lock the **first** match:
  * `crates/infynitae/src/main.rs:447-474`: `OUTPUT_SCALE`, `SCALING_FILTER`, `DIRECT_SCANOUT`, and `VRR_ENABLED|VRR|ADAPTIVE_SYNC` guard with `.is_none()`, so the first valid line wins and `VRR_ENABLED="auto"` cannot reset an earlier `"on"`.
  * `crates/infynitae/src/restore.rs:792-796`: `session_restore_from` returns on the first `SESSION_RESTORE=` line.
  * `live/wallpaper/infynitae-wallpaper.c:746-759`: `WALLPAPER` and `WALLPAPER_MODE` guard with `target[0] == '\0'` / `mode[0] == '\0'` (first-wins), while `WALLPAPER_PARALLAX` in the same loop is last-wins.
  * `live/settings.sh:1358`: `cmd_get` uses `head -1`.
  * `live/control-menu:174`: `grep -qE '^ENABLE_REPLAY_BUFFER=...'` matches any earlier enabled line even if overridden later in the file.
* **Proved by test**: `audit_config_session_restore_last_line_wins`.

### 9. `WINDOW_CORNERS` vs `CORNERS` clamp (`24` vs `28`), fallback, and cache mismatches

* `config/config:197-210` specifies `WINDOW_CORNERS` (`0..=24`, default `8`) for windows and UI unless `CORNERS` (`0..=28`) overrides UI corners.
