# INC-12 — independent review, round 2 (2026-10-16)

Status: **REVIEW. Verdict: INC-12 stays EXPERIMENTAL** — not ratified. Subject:
`experimental/inc-12-xwayland-satellite` (`989de64`, after round 1) plus
`fix/inc-12-satellite-runtime-dir-2026-10-16` (this branch: `1ef3e5d` and the round-2 commit).
Brief "Final Ratification Gates and Guided Runtime Readiness", §6.

## Areas reviewed

| Area | Result |
|---|---|
| Satellite runtime directory (`1ef3e5d`) | Correct: private `<runtime>/infynitae-satellite-<pid>-<n>` (0700) per satellite, session socket by absolute path, removed after reaping (crash before restart, shutdown, failed spawn). Verified at runtime: nested run 2 left no `xwls-*`. |
| X display cookie | Correct: 16 bytes from `/dev/urandom`, MIT-MAGIC-COOKIE-1, FamilyWild entry for the display number, file created exclusively with 0600 in the runtime dir, given to the satellite (`-auth`) and to the session's clients (`XAUTHORITY`), removed on drop. Runtime: a client without the cookie is refused (nested runs 1–2). **R2-3** below for a crash. |
| Display ownership | Correct: `:1 … :63` only (never `:0`), lock + both sockets held for the session, stale locks of our uid reclaimed; abstract socket access is guarded by the cookie. |
| Activation policy | Correct semantics (round-1 R1/R2: token validated only from the focused client, fresh seat serial, < 10 s, single use; Strict default). **R2-2** below: storage was unbounded. |
| Process environment isolation | Correct: session clients get the session's `WAYLAND_DISPLAY`, its `DISPLAY`/`XAUTHORITY` or none; `WAYLAND_SOCKET`, `XDG_ACTIVATION_TOKEN`, `DESKTOP_STARTUP_ID` removed; the satellite gets no `DISPLAY`/`XAUTHORITY`/`NOTIFY_SOCKET`. Other variables (e.g. the D-Bus address) pass through by design (a session's clients belong to the user's session); the runtime runs disabled D-Bus. |
| Restart behaviour | Correct: Crashed → backoff → Running on the same display; repeated exits → Degraded (X11 off, no `DISPLAY` for new clients). Runtime: `kill -9` of the satellite ended its X client and a new satellite served `:1` (nested runs 1–2; T1 `a_satellite_restarts_on_the_same_display_and_its_clients_die_with_it` on the runtime line). |
| Dependency on INC-6 | Confirmed: satellite 0.8.3 needs `wp_viewporter` (INC-6). INC-12 cannot be integrated or exit before INC-6 is ratified and integrated; its real-satellite T1 tests pass only on lines that contain INC-6. |

| # | Finding | Severity | Status |

**Verdict:** no open defect of INC-12 itself after this round; it **stays EXPERIMENTAL** until
criteria 1–5 are met.
