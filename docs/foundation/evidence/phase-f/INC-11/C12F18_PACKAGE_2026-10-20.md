# C12.F18 — prepared amendment package (Phase F: INC-11, the trusted shell) — PREPARED, NOT ADOPTED

Status: **PREPARED.** Records the normative consequences of the owner decisions of 2026-10-20
(`DECISION_RECORD_2026-10-20.md`) for adoption as layer §C12.F18. Until adopted (the layer text in
FOUNDATION_ARCHITECTURE, `F_LAYERS`, INV rows and fixtures, as for C12.F17), the living text below
is unchanged and this package is not normative.

## C12.F18.1 C7.1 — admission site (D1)

Current: "Admission: `SO_PEERCRED` uid must equal the compositor's uid." (unchanged) and
"Crate: `infynitae-ipc` … Deps: `core` only (+ a serialization crate)."
Proposed addition: "The composition root (the binary) binds the socket and performs the
`SO_PEERCRED` check (through `rustix`, safe API); `infynitae-ipc` receives admitted connections and
keeps `core` as its only dependency. `tools/verify-architecture` allows `rustix` for the binary
only." The socket path stays `$XDG_RUNTIME_DIR/infynitae/shell.sock`; a socket served by a live
compositor is never replaced.

## C12.F18.2 C7.2 — the Foundation 01 shell vocabulary (D3, D5, D6)

The commands of INC-11 (no longer "illustrative" for them): `Navigate{output, to: Element |
CanvasPos | Delta}` at the camera's current zoom (no history entry), `ViewportFit{output,
element}`, `ViewportRestore{output}`, `Focus{element}`, `AcknowledgeAttention{element}`,
`MoveElement{element, to}`; queries Snapshot, Subscribe, Unsubscribe. Camera commands are refused
while the output presents (C12.F17 Q1 B scope 2) or an interaction owns the pointer.

## C12.F18.3 C7.3 / INV-SCALE-3 — shell streams (D8)

A command may carry `stream: begin | step | end`; begin and step open the `ShellStream` epoch,
end is its explicit end-of-stream; a connection that closes ends the stream it opened.

## C12.F18.4 OBJ-01/OBJ-02 — toplevel metadata (D9)

Stage records carry the toplevel's title and app_id (each ≤ 4096 bytes), written by the adapter
on `set_title`/`set_app_id` through `Core::toplevel_metadata`; read by the shell; never read by
any Core decision.

## C12.F18.5 INV-STAGE-3 — the instance across runs

`InstanceId` differs between compositor runs (element ids restart at 1 in every process; a shell
outlives a restart), not only between Cores of one process.

## C12.F18.6 Events (D7)

Events are the difference between successive derived copies, each stamped with the generation it
belongs to (several events may share one); a reply carries the generation that resulted.
