## 2. Discovery of Test-Sensitivity Defect `INC2-F07`

During testing of Mutation J, the adversarial reviewer inspected both locations in `entry.rs` where `self.frames.retain(|(o, _)| *o != output)` appears:
1. `output_disconnected` (line 143): Covered by test `disconnect_drops_the_output_frame`.
2. `output_reconfigured` (line 120): When line 120 was deleted in scratch, **all 75 workspace tests passed**.

### Sensitivity Attack Proof
An independent test was authored in scratch:
```rust
#[test]
fn reconfiguration_drops_the_output_frame() {
    let (mut c, _, _, mut t) = Core::new(PersistedCameras::default());
    let (a, _) = c.output_connected(&mut t, desc("A")).unwrap();
    let id = c.toplevel_created();
    // Commit window and populate frame...
    c.render_list(a).unwrap();
    let p_before = crate::geom::OutputLogicalPoint { x: 970.5, y: 550.5 };
    assert!(c.hit_test(a, p_before).is_some());
    // Reconfigure to smaller mode 800x600 where p_before is out of bounds
    c.output_reconfigured(&mut t, a, desc_k(key("A"), (800, 600), Transform::Normal, 120, 60_000)).unwrap();
    // Stale frame must NOT survive
    assert_eq!(c.hit_test(a, p_before), None, "stale frame survived reconfiguration");
}
```
With line 120 intact, this test passes. With line 120 commented out, this test fails with exit code 101.
Because no existing test in the test suite performs a `hit_test` after `output_reconfigured`, this constitutes an open **Level B Test-Sensitivity Defect (`INC2-F07`)**.

## 3. Test Oracle Independence Audit

Following the lesson of `INC1-F06`, all test assertions were audited to verify that expected values are not generated by the production code under test:
- **T0 Geometric Tests:** Assert hardcoded numeric literals (e.g. `(960.0, 540.0)`, `(Some(pos(17, -3)), Some(1.0))`).
- **Popup Target Test:** Rewritten with hand-calculated constants (`(-960, -540)`, `(-548, -308)`). Production helper `View::unproject` is NOT used as an oracle.
- **T1 Lockstep Wire Tests:** Assert client wire logs against string literals (`"enter W 1"`, `"mode 1920x1080@60000"`, `"sync #1 1"`).
- **Transform Matrix Tests:** `expected_view(t)` is an independent test-local function; `checks()` inspects raw pixel arrays in CPU framebuffer `Fb`.
