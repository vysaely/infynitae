## Working beside another agent

Claude and agy both work on this repository and do not see each other's sessions. Before starting
anything (a branch, a pull request, a merge), read "Working on now" at the top of
`~/.claude/projects/-home-vysaely/memory/open-tasks.md`, add your line there
(`who | when | what | branch`), and remove it with a dated result line at the end of that file when
you finish. Do not merge another agent's draft pull request; comment on it instead.
